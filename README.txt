# Rathina Cholan B — Portfolio

## Run locally
Open `index.html` in Chrome/Edge/Firefox.

## Publish online
Upload the contents of this folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.

## Included functionality
- Responsive desktop/mobile design
- Smooth scrolling navigation
- Scroll-reveal animations using IntersectionObserver
- Active navigation section highlighting
- Mobile hamburger menu
- Back-to-top button
- Working email and phone links
- Contact form that opens the user's email application
- Resume content based on the supplied resume
